# Music Genre Classification

A Machine Learning project that classifies music tracks into different genres using audio features from the GTZAN Music Genre Dataset.

## Project Overview

The aim of this project is to build and compare different Machine Learning models for music genre classification.

The project uses extracted audio features and applies multiple classification algorithms to predict the genre of a music track.

## Dataset

The project uses the **GTZAN Music Genre Dataset**, which contains 1,000 audio tracks belonging to 10 different music genres.

## Machine Learning Algorithms

The following models were implemented and compared:

* Decision Tree
* Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)
* Random Forest

## Results

| Model         | Accuracy |
| ------------- | -------: |
| Decision Tree |      61% |
| SVM           |      65% |
| KNN           |      71% |
| Random Forest |      78% |

Among the tested models, **Random Forest achieved the highest accuracy of 78%**.
